# 0.2.0 — 2026-10-17

## Added

- **Point-batch progress:** accept up to 1,000 positions and validate/sample the first 100, returning counts and a call-local `next_offset` for sliced continuation (#12).
- **`vertical_reference`:** every successful tool result explains each answering dataset's height reference on both response surfaces, including unverified references and mixed-datum limitations; heights are not transformed (#13).

## Changed

- Reject antipodal profile segments, including previously accepted endpoint-only profiles; add an intermediate waypoint to select the route (#9).
- **Packaging:** align registry npm launch entries, Docker musl pruning, CodeQL categories, and development scripts/skills with the framework; use Bun 1.4.2 → 1.4.3 in container stages.

## Fixed

- **Near-antipodal profiles:** use stable vector-angle distance and interpolation while preserving submitted vertex indices in ambiguity errors (#9).
- **Node provider transport:** use an owned HTTP/1.1-only dispatcher for both providers, excluding the implicated HTTP/2 idle-reaper path; Bun retains native fetch. The intermittent crash was not deterministically reproduced (#15).
- **USGS fixtures:** cover HTTP-200 table-not-found responses as coverage misses.
