# 0.3.0 — 2026-10-28

## Added

- Publish the elevation-guide skill as an MCP resource for route, terrain-refinement, and sightline workflows.
- Include the guide in npm, Docker, MCPB, and plugin installations; expose it through the MCP Skills extension and `skill://elevation-guide/SKILL.md`.
- Add the Agent Plugins 1.0.0 root manifest and stdio connection configuration, retaining the Claude Code and Codex overlays.

## Changed

- HTTP defaults to stateless when MCP_SESSION_MODE is unset; an explicit value still overrides it.
- Source attribution trailers use inline code for single-line values and fenced literals for multiline values, preserving each line.
- Refresh plugin descriptions, keywords, framework assets, packaging validation, audit classification, and the bug report Environment form. Set the dependency minimum release age to one day.
- Consolidate README connection and runtime setup examples and document the guide's interpretation gates.
- Run Docker stages on Bun 1.4.3 → 1.4.4.

## Fixed

- Preserve SDK runtime modules under `dist/ext/skills/` while removing dependency-root agent documentation from MCPB bundles. Strip root development paths, node-gyp build output, and build-only dependency files from those bundles.
