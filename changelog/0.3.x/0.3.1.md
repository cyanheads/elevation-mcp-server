# 0.3.1 — 2026-11-11

## Changed

- Profiles, grids, and sightlines batch up to 50 positions per 3DEP ImageServer request. EPQS fills unresolved positions within the existing sampling budget (#21).
- Profile and sightline requests for 251–1,000 samples run at 250 and disclose the served count. Set `ELEVATION_CLAMP_LIMITS=false` to require counts within the advertised cap (#20).
- Clear and indeterminate sightlines disclose when sample spacing can miss terrain between samples (#19).
- Refresh framework skills, bundle cleanup, packaging checks, and release tooling.

## Fixed

- `elevation_get_points` reads UTC acquisition dates from the 3DEP raster catalog. Missing dates produce a notice while preserving the elevations (#22).
- Optional numeric and boolean inputs accept unambiguous string values. Set `ELEVATION_REPAIR_OPTIONAL_SCALARS=false` to require JSON numbers and booleans (#18).
