# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-01

Line of sight takes a water level for lines over USGS 3DEP bay bathymetry and reports first Fresnel zone clearance for radio links; profile spacing notices key on the finest source and hold at the 250-sample cap.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — four tools for point elevations, route profiles, elevation grids, and terrain line of sight, answered by USGS 3DEP inside its coverage and Open Topo Data (SRTM, then Mapzen) elsewhere, with no API key; every value names the dataset that answered it.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
